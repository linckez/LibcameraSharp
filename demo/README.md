# Demos

Small programs that show what the SDK is for.

| Demo | What it shows |
|---|---|
| [PhotoBooth](PhotoBooth/) | A console app: list the cameras, see what one can do, watch frames, take a photo as JPEG and DNG, then lock the exposure and take another |
| [StreamingCamera](StreamingCamera/) | A Pi webcam in one ASP.NET Core file: live H.264 as MP4, and MJPEG, to a browser |

Run one on the Pi with `dotnet run --project demo/<name>`.
